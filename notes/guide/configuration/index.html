配置结构

约 1037 字大约 3 分钟

2026-01-06

站点配置被拆成三个文件，各自职责单一：

docs/.vuepress/
├── config.ts        # VuePress 站点配置：lang / title / bundler
├── plume.config.ts  # Plume 主题配置：logo / 集合 / 搜索 / 页脚
├── navbar.ts        # 导航栏
├── client.ts        # 客户端配置：引入自定义样式、朗读交互
├── public/          # 静态资源：logo、头像、背景图
└── styles/          # 自定义样式

config.ts

只保留站点级配置，主题部分通过 plumeTheme(themeConfig) 注入：

import { defineUserConfig } from 'vuepress'
import { viteBundler } from '@vuepress/bundler-vite'
import { plumeTheme } from 'vuepress-theme-plume'
import themeConfig from './plume.config.js'

export default defineUserConfig({
  lang: 'zh-CN',
  title: 'Bennett',
  theme: plumeTheme(themeConfig),
  bundler: viteBundler(),
})

lang 必须正确设置

主题依靠 lang 决定界面文案语言，缺失时会回落为英文。

除上例的基本项外，本项目的 config.ts 还做了两件事：用 head 指定 favicon 与主题色，以及通过 extendsMarkdown 注册 ::: vocab-card 容器（见 styles/vocab-card.css）。

plume.config.ts

主题能力全部在这里开关。核心是 collections：

import { defineThemeConfig } from 'vuepress-theme-plume'
import { navbar } from './navbar.js'

export default defineThemeConfig({
  logo: '/images/logo.png',
  logoDark: '/images/logo.png',
  // 强制深色；换成 'dark' 只是默认深色，导航栏仍保留明暗切换按钮
  appearance: 'force-dark',

  profile: {
    avatar: '/images/avatar.png',
    name: 'Bennett',
    description: '保持好奇，持续记录',
    circle: true,
  },

  navbar,

  // 自动补全 frontmatter：permalink 用 'filepath'，按文件路径生成可读链接
  autoFrontmatter: { permalink: 'filepath' },

  collections: [
    {
      type: 'post',
      dir: 'blog',
      title: '博客',
      link: '/blog/',
      pagination: 10,
      tags: true,
      archives: true,
      // 文章都放在 blog 根目录，没有层级分类，关掉分类页避免空页
      categories: false,
      // 列表页顶部显示满屏个人卡片
      profile: true,
    },
    {
      type: 'doc',
      dir: 'notes',
      title: '笔记',
      // 不写 linkPrefix 时默认为 /${dir}/，即 /notes/
      linkPrefix: '/notes/',
      // 按目录结构自动生成侧边栏
      sidebar: 'auto',
    },
    {
      type: 'doc',
      dir: 'english',
      title: '英语',
      linkPrefix: '/english/',
      // 自动生成会直接取目录名（vocabulary），无法改成中文，
      // 所以「词汇」这一层显式声明；章节内层仍用 items: 'auto' 自动展开
      sidebar: [
        {
          text: '词汇',
          collapsed: false,
          items: [
            {
              text: 'CH1 自然地理',
              prefix: '/english/vocabulary/physical-geography/',
              collapsed: false,
              items: 'auto',
            },
          ],
        },
      ],
    },
  ],

  search: { provider: 'local' },

  // 关闭文档页底部的「最后更新于 / 贡献者」两行
  // 它们由 git 提交记录渲染（时间取最后一次提交、贡献者取提交作者），等于公开作者信息
  lastUpdated: false,
  contributors: false,

  // 页脚只保留版权行：message 必须显式置空，
  // 省略该字段会回落到主题默认的 “Powered by VuePress”
  footer: { message: '', copyright: 'Copyright © 2026 Bennett' },

  // 文章底部版权协议
  copyright: { license: 'CC-BY-4.0', author: { name: 'Bennett' } },
})
字段作用
type: 'post'聚合为博客，自动生成文章列表、标签页、归档页
type: 'doc'聚合为文档，sidebar: 'auto' 时按目录生成侧边栏
linkpost 集合的文章列表页地址，如 /blog/
linkPrefixdoc 集合的链接前缀，省略时默认 /${dir}/
sidebar'auto' 走目录；也可手写分组，items: 'auto' 让某一层自动展开
pagination文章列表每页数量
categories分类页开关；文章都在根目录时应关闭，否则是空页
profilepost 集合的列表页是否显示个人卡片
autoFrontmatter自动补 createTime / permalink 等字段
lastUpdated文档页底部「最后更新于」，取 git 提交时间；默认开启
contributors文档页底部「贡献者」，取 git 提交作者；默认开启

两个容易忽略的默认值

footer.message 省略时会渲染主题默认的“Powered by …”，要彻底不显示必须显式写空字符串；bulletin 不配置也可能渲染出空壳浮窗，不用公告时应设 { enablePage: false }。

隐藏「最后更新于 / 贡献者」

这两行来自本地 git 记录，贡献者会直接显示提交作者名与 GitHub 用户名。不想公开时在主题配置里设 lastUpdated: false 与 contributors: false，它们所在的 .edit-info 区块会连同 DOM 一起消失，下文的翻页导航不受影响。

navbar.ts

导航项支持二级菜单：

import { defineNavbarConfig } from 'vuepress-theme-plume'

export const navbar = defineNavbarConfig([
  { text: '首页', link: '/' },
  { text: '笔记', link: '/notes/' },
  { text: '博客', link: '/blog/' },
  {
    text: '更多',
    items: [
      { text: '英语', link: '/english/' },
      { text: '标签', link: '/blog/tags/' },
      { text: '归档', link: '/blog/archives/' },
      { text: '主题文档', link: 'https://theme-plume.vuejs.press' },
    ],
  },
])

items 即二级菜单；外链会自动加上跳转图标。
