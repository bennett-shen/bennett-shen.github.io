5 规划干系人参与

约 1600 字大约 5 分钟

2026-11-21

规划干系人参与是根据干系人的需求、期望、利益和对项目的潜在影响，制定项目干系人参与项目的方法的过程。本过程的主要作用是，提供与干系人进行有效互动的可行计划。本过程应根据需要在整个项目期间定期开展。

为满足干系人多样性的信息需求，应在项目生命周期早期制订一份有效的计划，然后随着干系人群体的变化定期审查和更新。明确最初的干系人群体之后，就应编制第一版干系人参与计划。触发计划更新的情况主要包括（4 种）：①项目新阶段开始；②组织结构或行业内部发生变化；③新的个人或群体成为干系人，现有干系人不再是群体成员，或特定干系人对项目成功的重要性发生变化；④其他项目过程（如变更管理、风险管理或问题管理）的输出导致需要重新审查参与策略。

输入工具与技术输出
项目章程、项目管理计划、项目文件、协议、事业环境因素、组织过程资产专家判断、数据收集、数据分析、决策、数据表现、会议干系人参与计划

5.1 输入

项目章程包含与项目目的、目标和成功标准有关的信息。项目管理计划中，资源管理计划提供团队成员及其他干系人的角色和职责；沟通管理计划既提供沟通策略，又收录来自干系人管理各过程的相关信息；风险管理计划可能包含风险临界值或风险态度，有助于选择最佳的参与策略组合。

项目文件主要包括：假设日志（可能与特定干系人关联的假设条件和制约因素）、风险登记册（把风险与具体干系人关联，指定风险责任人或受影响者）、干系人登记册（清单、分类情况和其他信息）、项目进度计划（活动与具体干系人关联）、问题日志（解决其中的问题需与受影响干系人额外沟通）、变更日志（变更常与提出者、审批者或受影响者关联）。

协议方面，规划承包商及供应商参与时，通常需要与组织内的采购小组和合同签署小组合作，以确保有效管理。事业环境因素包括组织文化和治理框架、人事管理政策、干系人风险偏好、已确立的沟通渠道等；组织过程资产包括社交媒体与道德安全政策程序、问题风险变更和数据管理程序、组织对沟通的要求、信息制作交换储存检索的标准化指南、经验教训知识库、支持有效参与的软件工具等。

5.2 工具与技术

1. 专家判断：组织内外部的政策和权力结构；组织及组织外部的环境和文化；干系人参与过程使用的分析和评估技术；沟通手段和策略；以往项目中关于干系人、干系人群体及干系人组织的特征的知识。

2. 数据收集：标杆对照，即将干系人分析的结果与其他被视为具备引领级的组织或项目的信息进行比较。

3. 数据分析：假设条件和制约因素分析，用于合理裁剪参与策略；根本原因分析，用于识别是什么原因导致干系人处于某种支持水平，以便选择适当策略改进其参与水平。

4. 决策：优先级排序或分级。应对干系人需求以及干系人本身排序，具有最大利益和最高影响的干系人通常应排在优先级清单的最前面。

5. 数据表现

思维导图用于对干系人信息、相互关系以及他们与组织的关系进行可视化整理；干系人参与度评估矩阵用于将干系人当前参与水平与期望参与水平进行比较。

参与水平表现
不了解型（不知晓）不知道项目及其潜在影响
抵制型知道项目及其潜在影响，但抵制项目工作或成果可能引发的任何变更，不会支持项目工作或项目成果
中立型了解项目，但既不支持也不反对
支持型了解项目及其潜在影响，并且会支持项目工作及其成果
领导型了解项目及其潜在影响，而且积极参与以确保项目取得成功

矩阵以 C 表示每个干系人的当前参与水平，D 表示项目团队评估出的、为确保项目成功所必不可少的参与水平（期望水平）。示意如下：

干系人不了解抵制中立支持领导
干系人 1CD
干系人 2CD
干系人 3DC
应根据每个干系人当前与期望参与水平的差距开展必要的沟通，有效引导干系人参与项目；弥合这一差距是监督干系人参与中的一项基本工作。

6. 会议：用于讨论规划干系人参与所需信息，以便制订良好的干系人参与计划。

5.3 输出

干系人参与计划是项目管理计划的组成部分，制订了干系人有效参与和执行项目决策的策略和行动。该计划可以是正式的或非正式的、非常详细的或高度概括的，取决于项目的需要和干系人的期望。干系人参与计划主要包括调动干系人个人或群体参与的特定策略或方法，并记录针对已识别干系人的商定沟通策略。
