CH6.7 精度、误差与意外

Pinpoint

/ˈpɪnpɔɪnt/ · verb · 动词 / adj · 形容词 / noun · 名词

核心释义（Definitions）

  • 动词：准确定位；精确指出（原因、问题）
  • 形容词：精确的，精准的

核心搭配（Collocations）

搭配中文释义
pinpoint the cause准确指出原因
pinpoint the location精确定位
with pinpoint accuracy以极高的精度
pinpoint exactly精确指出

例句（Examples）

Writing Task 1 The map pinpoints the exact sites where samples were taken.

该地图精确标出了取样地点。

Writing Task 2 It is easier to describe a problem than to pinpoint its cause.

描述问题比准确指出其原因容易得多。

Speaking Doctors couldn't pinpoint what was wrong for weeks.

好几周医生都没法确定问题在哪。

同义替换（Synonyms）

词汇中文释义使用区别
identify识别泛指认出，未必精确
locate定位多用于地点，也可指找到
specify明确说明侧重"讲清楚"，非"找出来"

词根与记忆（Word Formation）

  • Root: pin（针）+ point（点）复合而成
  • Family: pinpoint 精确定位 / pin 别针；固定 / point 点；观点 / pointer 指示物
  • Memory Tip: 想象用一枚针顶住地图上的一点——"精确到一个点"。所以它比 find 多了"精确"这层意思。

常见错误（Common Mistakes）

  • 及物动词，需带宾语：pinpoint the problem。
  • 拼写 pin-point 常连写，作形容词时也可带连字符。
  • 不用于"精确测量数值"，那用 measure precisely。

Accurate

/ˈækjərət/ · adj · 形容词

核心释义（Definitions）

  • 准确的，精确的（与事实相符）
  • （仪器）精准的；（描述）如实的

核心搭配（Collocations）

搭配中文释义
accurate data准确的数据
an accurate description如实的描述
highly accurate高度精确的
accurate to within误差在……以内

例句（Examples）

Writing Task 1 The chart provides accurate figures for the first five years only.

该图表只提供了前五年的准确数据。

Writing Task 2 Accurate prediction is rare; accurate description is achievable.

准确预测很罕见，准确描述却做得到。

Speaking Weather apps are accurate about a day ahead, not a week.

天气应用只能准确预报一天，不是一周。

同义替换（Synonyms）

词汇中文释义使用区别
precise精确的强调细节精确、可复现
exact确切的强调完全一致，无误差
correct正确的只判对错，不含精度

词根与记忆（Word Formation）

  • Root: 拉丁 accuratus ← accurare（用心对待）= ad- + cura（关心）
  • Family: accurate 准确的 / accuracy 准确度 / accurately 准确地 / inaccurate 不准确的 / cure（同源"照料"）
  • Memory Tip: cura 是"关心、照料"，accurate 本义是"用心做出来的"——用心才准确。名词 accuracy 不可数。

常见错误（Common Mistakes）

  • 名词是 accuracy（不可数），形容词才是 accurate。
  • 拼写 acc-urate，双 c 单 r。
  • accurate 与 precise 有别：前者"对"，后者"细"。

Precise

/prɪˈsaɪs/ · adj · 形容词

核心释义（Definitions）

  • 精确的，精密的（细节清楚、可复现）
  • 恰好的；严谨的（人）

核心搭配（Collocations）

搭配中文释义
precise measurements精确的测量
to be precise确切地说
at that precise moment就在那一刻
precise instructions明确的指示

例句（Examples）

Writing Task 1 The diagram gives precise measurements for each component.

该示意图给出了每个部件的精确尺寸。

Writing Task 2 Vague goals produce vague effort; precise goals can be met or missed.

模糊的目标带来模糊的努力，精确的目标才能被达成或落空。

Speaking At three o'clock, to be precise — not a minute later.

确切说是三点整，一分钟都不能晚。

同义替换（Synonyms）

词汇中文释义使用区别
exact确切的强调完全无误，语气更强
accurate准确的强调与事实相符
specific具体的强调明确，非"精细"

词根与记忆（Word Formation）

  • Root: 拉丁 praecisus（切短的）← praecidere = prae- + caedere（切）
  • Family: precise 精确的 / precision 精度 / precisely 恰好；确切地 / concise（同源"切短"）
  • Memory Tip: caedere 是"切"，把多余的部分切掉，剩下的就"精确"。concise（简洁）也是"切短"的同族词。

常见错误（Common Mistakes）

  • 名词 precision 不可数：with great precision。
  • to be precise 是插入语，前后用逗号隔开。
  • 拼写 pre-cise，重音在第二音节。

Correct

/kəˈrekt/ · adj · 形容词 / verb · 动词

核心释义（Definitions）

  • 形容词：正确的，对的；恰当的
  • 动词：改正，纠正

核心搭配（Collocations）

搭配中文释义
the correct answer正确答案
correct a mistake改正错误
correctly正确地
politically correct政治正确的

例句（Examples）

Writing Task 1 The chart shows the correct proportion of spending in each category.

该图表显示了各类支出的正确比例。

Writing Task 2 Being corrected in public teaches people to stay quiet, not to be right.

当众被纠错，教会人的是闭嘴，而不是正确。

Speaking Correct me if I'm wrong, but didn't we already try this?

如果我记错了你纠正我，这事我们不是试过了吗？

同义替换（Synonyms）

词汇中文释义使用区别
right对的口语，最常用
accurate准确的强调与事实相符，非对错
proper恰当的强调合乎规范

词根与记忆（Word Formation）

  • Root: 拉丁 corrigere = com- + regere（使直、引导）
  • Family: correct 正确的；改正 / correction 改正 / correctly 正确地 / direct 指引（同源 regere）
  • Memory Tip: reg = 使直、统治，correct 是"把弯的掰直"。同族有 direct（指引方向）、regular（规则的）、regulate（管制）。

常见错误（Common Mistakes）

  • 动词"改正"及物：correct the error。
  • 副词 correctly 修饰动词，别用 correct 当副词。
  • 拼写 cor-rect，双 r。

Error

/ˈerə(r)/ · noun · 名词

核心释义（Definitions）

  • 错误，差错（计算、技术、判断上的）
  • 误差（测量值与真值之差）

核心搭配（Collocations）

搭配中文释义
human error人为失误
a margin of error误差范围
error rate错误率
in error错误地

例句（Examples）

Writing Task 1 The chart shows the error rate falling as the sample size grows.

该图表显示随着样本量增加，误差率下降。

Writing Task 2 Most medical error is systemic rather than personal.

多数医疗差错是系统性的，而非个人造成的。

Speaking The order arrived twice because of a system error.

因为系统出错，订单来了两份。

同义替换（Synonyms）

词汇中文释义使用区别
mistake错误多指人的判断失误
fault故障；过错强调责任归属
inaccuracy不准确强调精度不足，未必算错

词根与记忆（Word Formation）

  • Root: 拉丁 error ← errare（漫游、走偏）
  • Family: error 错误 / err 犯错 / erroneous 错误的 / erratic 不规律的
  • Memory Tip: errare 是"走偏了路"，所以 error 的画面是"偏离正途"。err 是动词（To err is human），erroneous 是形容词。

常见错误（Common Mistakes）

  • 可数或不可数均可：an error / human error。
  • "误差范围"是 margin of error，固定搭配。
  • 拼写 er-ror，双 r；erroneous 也是双 r。

Mistake

/mɪˈsteɪk/ · noun · 名词 / verb · 动词

核心释义（Definitions）

  • 名词：错误，过失（判断或行为上的）
  • 动词：误认，把……错当成（mistake A for B）

核心搭配（Collocations）

搭配中文释义
make a mistake犯错
by mistake错误地，无意中
mistake A for B把 A 误当成 B
a costly mistake代价高昂的错误

例句（Examples）

Writing Task 1 The diagram shows the mistakes that occur when the labels are swapped.

该示意图显示了标签互换时出现的错误。

Writing Task 2 Treating a symptom as a cause is the most common mistake in policy.

把症状当作病因，是政策中最常见的错误。

Speaking I mistook him for his brother — they look identical.

我把他当成他哥了，两人长得一样。

同义替换（Synonyms）

词汇中文释义使用区别
error错误偏技术、计算，更正式
slip小疏忽强调一时不慎
blunder大错语气重，含愚蠢意味

词根与记忆（Word Formation）

  • Root: mis-（错误地）+ take（拿、取）
  • Family: mistake 错误 / mistaken 错误的 / mistakenly 错误地 / take 拿
  • Memory Tip: mis- 表"错"：mistake（拿错）、misunderstand（理解错）、mislead（误导）。"拿错了"就是 mistake 的字面义。

常见错误（Common Mistakes）

  • 固定搭配 make a mistake，不用 do a mistake。
  • by mistake（无意地）与 on purpose（故意）相对。
  • 动词过去式 mistook，过去分词 mistaken。

Flaw

/flɔː/ · noun · 名词

核心释义（Definitions）

  • 缺陷，瑕疵（设计、论证、材料上的）
  • （性格的）弱点

核心搭配（Collocations）

搭配中文释义
a design flaw设计缺陷
a fatal flaw致命缺陷
a flaw in the argument论证中的漏洞
character flaw性格弱点

例句（Examples）

Writing Task 1 The diagram shows where a flaw in the casting caused the pipe to crack.

该示意图显示了铸件缺陷导致管道开裂的位置。

Writing Task 2 The policy's fatal flaw is that it assumes people behave rationally.

这项政策的致命缺陷在于它假定人会理性行事。

Speaking There's a flaw in that plan — nobody's checked the budget.

这计划有个漏洞，没人核对过预算。

同义替换（Synonyms）

词汇中文释义使用区别
defect缺陷更技术，多指产品不合格
weakness弱点中性，可用于人、方案
fault故障；过错强调责任或功能失灵

词根与记忆（Word Formation）

  • Root: 古诺斯语 flaga（石板、薄片），"裂纹"义发展而来
  • Family: flaw 缺陷 / flawed 有缺陷的 / flawless 无瑕的
  • Memory Tip: flawless（完美无瑕）是写作加分词：a flawless performance。与 defect 相比，flaw 更常用于抽象论证。

常见错误（Common Mistakes）

  • 可数：a flaw / flaws。
  • 介词用 in：a flaw in the design。
  • 拼写 flaw，别写成 flau。

Wrong

/rɒŋ/ · adj · 形容词 / adv · 副词 / noun · 名词

核心释义（Definitions）

  • 形容词：错误的；不合适的；出故障的
  • 副词：错误地（go wrong）
  • 名词：错误，不义（不可数）

核心搭配（Collocations）

搭配中文释义
go wrong出问题，出错
the wrong choice错误的选择
something is wrong with……出了问题
right and wrong是非

例句（Examples）

Writing Task 1 The chart shows what went wrong in the third year of the trial.

该图表显示了试验第三年出了什么问题。

Writing Task 2 It is wrong to assume that technology always saves labour.

认定技术总能省人力，是错的。

Speaking I got on the wrong train and ended up at the coast.

我上错车，最后到了海边。

同义替换（Synonyms）

词汇中文释义使用区别
incorrect不正确的正式，语气比 wrong 轻
mistaken弄错的多形容人、想法
faulty有故障的只用于设备、推理

词根与记忆（Word Formation）

  • Root: 古英语 wrang（不义）← 古诺斯语 rangr（歪的）
  • Family: wrong 错误的 / wrongly 错误地 / wrongdoing 不法行为 / wrongful 不正当的
  • Memory Tip: 本义是"歪的"——歪了就不对。go wrong 是最实用的短语：既能说"出错"，也能说"出故障"。

常见错误（Common Mistakes）

  • "出问题"用 go wrong，不用 become wrong。
  • 副词在英式里多用 wrongly（正式），口语常用 wrong。
  • something is wrong with + 名词，介词用 with。

Fault

/fɔːlt/ · noun · 名词

核心释义（Definitions）

  • 故障，毛病（设备）
  • 过错，责任；（地质）断层

核心搭配（Collocations）

搭配中文释义
a technical fault技术故障
at fault有责任，有过错
find fault with挑……的毛病
a fault line断层线；分歧线

例句（Examples）

Writing Task 1 The diagram shows the fault in the circuit that caused the fire.

该示意图显示了引发火灾的电路故障。

Writing Task 2 When systems fail, blaming the operator is usually the wrong question of fault.

系统失灵时，归咎操作员往往是问错了责任。

Speaking It's not your fault — the instructions were unclear.

不是你的错，说明写得不清楚。

同义替换（Synonyms）

词汇中文释义使用区别
defect缺陷多指产品制造问题
error错误偏数据与判断
blame责备动词，强调归责行为

词根与记忆（Word Formation）

  • Root: 古法语 faute ← 拉丁 fallere（欺骗、失误）
  • Family: fault 故障；过错 / faulty 有故障的 / faultless 无过的 / default 违约；默认
  • Memory Tip: fallere 是"失误、欺骗"，同族的 false（假的）、fail（失败）、default（未履行→默认）都指向"没做到"。

常见错误（Common Mistakes）

  • "是某人的错"说 It's sb's fault，不说 It's sb's mistake（mistake 指"错误的事"）。
  • faulty 是形容词"有故障的"，注意 -y。
  • at fault 不加 the：He was at fault。

Stumble

/ˈstʌmbl/ · verb · 动词

核心释义（Definitions）

  • 绊倒，踉跄（stumble on/over）
  • 说话结巴；（偶然）发现（stumble upon）
  • 受挫，失误

核心搭配（Collocations）

搭配中文释义
stumble over被……绊倒；说话打结
stumble upon / on偶然发现
stumble through磕磕绊绊地完成
stumble at the first step第一步就绊住

例句（Examples）

Writing Task 1 The diagram shows where the robot stumbles on uneven ground.

该示意图显示了机器人在不平地面上失稳的位置。

Writing Task 2 Most discoveries are stumbled upon by people who were looking for something else.

多数发现是找别的东西的人偶然碰上的。

Speaking I stumbled over the cable in the dark and dropped everything.

我在黑暗中被电线绊了一下，东西全掉了。

同义替换（Synonyms）

词汇中文释义使用区别
trip绊倒口语，多指脚被绊
stagger踉跄强调摇晃不稳
falter动摇；迟疑多用于信心、声音

词根与记忆（Word Formation）

  • Root: 古诺斯语 stumra（踉跄）
  • Family: stumble 绊倒 / stumbling block 障碍 / stumbler 蹒跚者
  • Memory Tip: stumbling block（绊脚石）是写作高频比喻：a major stumbling block to reform。stumble upon 则是"偶然发现"，很适合讲科研故事。

常见错误（Common Mistakes）

  • 被某物绊倒用 stumble over / on sth。
  • "偶然发现"用 stumble upon，不是 stumble into（后者指"误入"）。
  • 拼写 stum-ble，注意 -mb- 中 b 不发音。

Contingency

/kənˈtɪndʒənsi/ · noun · 名词

核心释义（Definitions）

  • 意外情况，偶发事件
  • 应急准备（contingency plan）

核心搭配（Collocations）

搭配中文释义
a contingency plan应急预案
contingency planning应急规划
in case of contingency如遇意外情况
a contingency fund应急资金

例句（Examples）

Writing Task 1 The chart includes a contingency allowance for unexpected repairs.

该图表包含了应对意外维修的预备金。

Writing Task 2 Complex systems fail not from single faults but from unplanned contingencies.

复杂系统的失败很少源于单一故障，而源于未加规划的意外。

Speaking We budgeted an extra ten per cent as a contingency.

我们多留了百分之十作应急。

同义替换（Synonyms）

词汇中文释义使用区别
emergency紧急情况强调已发生的危急状态
eventuality可能发生的事更书面，概率意味更淡
uncertainty不确定性指状态，不指具体事件

词根与记忆（Word Formation）

  • Root: 拉丁 contingere（接触、发生）= con- + tangere（触碰）
  • Family: contingency 意外 / contingent 依情况而定的；分遣队 / contact 接触 / tangible 可触摸的
  • Memory Tip: tang = 触碰，"碰到身上的事"就是偶发事件。contingent on（取决于）是学术写作常见搭配。

常见错误（Common Mistakes）

  • 可数：a contingency / contingencies。
  • 最常用的是 a contingency plan，别写成 contingency project。
  • 拼写 contin-gency，注意 -ng-。

Circumstance

/ˈsɜːkəmstəns/ · noun · 名词

核心释义（Definitions）

  • 情况，条件，环境（常用复数）
  • （复数）境况，经济状况

核心搭配（Collocations）

搭配中文释义
under no circumstances决不
in the circumstances在这种情况下
due to circumstances beyond our control由于不可控因素
living circumstances生活境况

例句（Examples）

Examples

Writing Task 1 The chart does not account for differences in local circumstances.

该图表没有考虑各地情况的差异。

Writing Task 2 Under no circumstances should cost alone decide which technology is adopted.

决不应仅凭成本决定采用哪项技术。

Speaking Given the circumstances, I think we did well.

在这种情况下，我觉得我们做得不错了。

同义替换（Synonyms）

词汇中文释义使用区别
situation情况最通用，不加介词短语
conditions条件强调外部条件
context背景强调解释所需的语境

词根与记忆（Word Formation）

  • Root: 拉丁 circumstantia = circum（环绕）+ stare（站立）
  • Family: circumstance 情况 / circumstantial 依情况的；间接的 / circum- 环绕 / stance 立场
  • Memory Tip: circum（环绕）+ stance（站）＝"围在周围的东西"，就是处境。同族的 circle、circuit、circumstance 都藏着"圈"。

常见错误（Common Mistakes）

  • under no circumstances 置于句首时，主句要部分倒装：Under no circumstances should you...
  • 表"在这种情况下"用 in the circumstances 或 under the circumstances，都成立但英式偏 in。
  • 拼写 circum-stance，注意 -mst-。
