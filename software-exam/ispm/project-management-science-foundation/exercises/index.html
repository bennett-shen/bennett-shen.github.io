一、选择题

1. 甲、乙、丙为三个独立项目，NPV 甲为 12 万元、乙为 15 万元、丙为 18 万元，三个项目的初始投资额相同，并且回收期相同，则应优先选择 ______ 项目进行投资。

A. 甲　　B. 乙　　C. 丙　　D. 甲或乙

参考答案

C

三个项目初始投资额相同、回收期相同，属于寿命期相同的互斥（可比）选择场景，此时应以净现值最大为优选准则。丙的 NPV 18 万元最大，故优先选择丙项目。

2. 基于下表数据计算，项目的净现值为（1），内部收益率为（2），基准折现率为 10%。

年末0123456
净现金流量/万元-50-804060606060

（1）A. 150　　B. 67.5　　C. 80　　D. 125.5

（2）A. 25.87%　　B. 15%　　C. 27.58%　　D. 23.26%

参考答案

（1）B　（2）A

净现值按 10% 逐期折现：

NPV = -50 - 80/1.1 + 40/1.1² + 60/1.1³ + 60/1.1⁴ + 60/1.1⁵ + 60/1.1⁶
    = -50 - 72.73 + 33.06 + 45.08 + 40.98 + 37.26 + 33.87 ≈ 67.5（万元）

内部收益率即使 NPV = 0 的折现率，用线性插值法逼近可得 IRR ≈ 25.87%（大于基准折现率 10%，项目可行）。

3. 购买一台设备，已知该设备的制造成本为 6000 元，售价为 8000 元，预计运输费需 200 元，安装费用为 200 元。该设备运行投产后，每年可加工工件 2 万件，每件净收入为 0.2 元。该设备的初始投资 ______ 年可回收。

A. 1.8　　B. 1.9　　C. 2　　D. 2.1

参考答案

D

初始投资应包括设备售价、运输费和安装费：

初始投资 = 8000 + 200 + 200 = 8400（元）
年净收益 = 2 万件 × 0.2 元/件 = 4000（元）
静态投资回收期 = 8400 ÷ 4000 = 2.1（年）

注意：设备的"制造成本"是干扰项，购买方付出的是售价加上运杂与安装费用。

4. 某工厂生产甲、乙两种产品，生产 1 kg 甲产品需要煤 9 kg、电 4 kW·h、油 3 kg，生产 1 kg 乙产品需要煤 4 kg、电 5 kW·h、油 10 kg。该工厂现有煤 360 kg、电 200 kW·h、油 300 kg。已知甲产品利润为 7000 元/kg，乙产品利润为 12000 元/kg，为了获取最大利润，应该生产甲产品（①）kg，乙产品（②）kg。

① A. 20　　B. 21　　C. 22　　D. 23

② A. 22　　B. 23　　C. 24　　D. 25

参考答案

① A　② C

设甲、乙产量分别为 x、y（kg），线性规划模型为

Smax = 7000x + 12000y
9x + 4y ≤ 360
4x + 5y ≤ 200
3x + 10y ≤ 300
x ≥ 0, y ≥ 0

三个资源约束两两求交并检验可行性，可行域的顶点中使目标函数最大的是 (x, y) = (20, 24)：此时煤 9×20+4×24 = 276 ≤ 360、电 4×20+5×24 = 200（恰好用完）、油 3×20+10×24 = 300（恰好用完），总利润 7000×20 + 12000×24 = 42.8 万元，为最优。

5. 图是某城市八个小区的通信线路图，图中标注的数字代表通信线路的长度（单位为 km），那么现在至少要架设 ______ km 的线路，才能保持八个小区的通信联通。

A. 19　　B. 20　　C. 21　　D. 22

参考答案

B

使 8 个小区（顶点）全部连通且线路总长度最短，即求该赋权连通无向图的最小生成树。可用破圈法（任取一圈、删去圈中权数最大的边、直至无圈）或避圈法（每次选取不构成圈的最小权边）求解，所得最小生成树各边权数之和为 20 km。

6. 某企业开发了一种新产品，拟定的价格方案有三种：较高价、中等价和较低价。估计这种产品的销售状态也有三种：销路较好、销路一般和销路较差。根据以往的销售经验，这三种价格方案在三种销路状态下的收益值如下表所示。

价格方案销路较好销路一般销路较差
较高价20118
中等价161610
较低价121212

企业一旦选择了某种决策方案，在同样的销路状态下，可能会产生后悔值（即所选决策方案产生的收益与最佳决策收益值的差值）。例如，如果选择较低价决策，在销路较好时，后悔值就为 8 万元。企业决定采用最小—最大后悔值决策标准（坏中求好的保守策略），为此，该企业应选择 ______ 决策方案。

A. 较高价　　B. 中等价　　C. 较低价　　D. 中等价或较低价

参考答案

B

先按各状态的最优收益（列最大值 20、16、12）计算后悔值表：

价格方案销路较好销路一般销路较差最大后悔值
较高价0545
中等价4024
较低价8408

最小—最大后悔值准则即"大中取小"：取各方案最大后悔值中的最小者，中等价为 4 万元，故应选择中等价方案。

二、计算分析题

1. 某项目设计方案总投资 2995 万元，投产后年经营成本 500 万元，年营业收入额 1500 万元，第 3 年末配套追加投资 1000 万元，计算期 5 年，基准收益率 10%，残值为零。试计算该方案的净现值并判断可行性。

参考答案

第 1、2、4、5 年净现金流量均为 1500 - 500 = 1000 万元，第 3 年因追加投资净现金流量为 0，第 0 年净现金流量为 -2995 万元。

NPV = -2995 + 1000/1.1 + 1000/1.1² + 0 + 1000/1.1⁴ + 1000/1.1⁵
    = -2995 + 909.1 + 826.4 + 0 + 683.0 + 620.9
    = 44.4（万元）

NPV = 44.4 万元 > 0，说明项目实施后除达到 10% 的基准收益率外，还有 44.4 万元的收益现值，方案可行。

2. 某公司有 400 万元用于投资甲、乙、丙三个项目，投资以百万元为计量单位。甲项目投资 0/100/200/300 万元对应收益 0/300/600/1000 万元；乙项目投资 0/100/200/300 万元对应收益 0/500/1000/1200 万元；丙项目必须投资，投资 100/200/300/400 万元对应收益 400/800/1100/1500 万元。试用动态规划方法确定使总收益最大的投资方案。

参考答案

以对甲、乙、丙的投资依次为第 1、2、3 阶段，状态变量 Sk 为投入第 k 至第 3 阶段的总投资额，递推公式为 fk(Sk) = max{ vk(xk) + f(k+1)(Sk - xk) }，边界条件 f4(S4) = 0。

第三阶段：f3(100)=400  f3(200)=800  f3(300)=1100  f3(400)=1500
第二阶段：f2(100)=400  f2(200)=900  f2(300)=1400  f2(400)=1800
第一阶段：f1(400)=max{0+1800, 300+1400, 600+900, 1000+400}=1800

S1 = 400 时取 x1 = 0，则 S2 = 400，查得 x2 = 200、x3 = 200。最优策略为（0, 200, 200），即甲不投资、乙投资 200 万元、丙投资 200 万元，总收益 1800 万元。
