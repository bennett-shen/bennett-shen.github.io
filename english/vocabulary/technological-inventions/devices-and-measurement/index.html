CH6.3 设备、工具与测量评估

约 8014 字大约 27 分钟

2026-11-20

Device

/dɪˈvaɪs/ · noun · 名词

核心释义（Definitions）

  • 装置，设备，仪器（为特定目的设计）
  • 手段，策略（文学、修辞手法）

核心搭配（Collocations）

搭配中文释义
a portable device便携设备
an electronic device电子设备
a device for doing sth用来做某事的装置
a safety device安全装置

例句（Examples）

Writing Task 1 The diagram shows a device that measures the flow of water through the pipe.

该示意图显示了一种测量管道水流量的装置。

Writing Task 2 Personal devices have become the main way people read the news.

个人设备已成为人们获取新闻的主要途径。

Speaking My phone is the only device I take on trips.

手机是我旅行时唯一带的设备。

同义替换（Synonyms）

词汇中文释义使用区别
gadget小装置口语，带调侃色彩
appliance家用电器多指家电，范围窄
instrument仪器精密测量、专业用途

词根与记忆（Word Formation）

  • Root: 古法语 devis ← deviser（划分、安排）← 拉丁 dividere
  • Family: device 装置 / devise 设计 / divide 划分 / division 分割
  • Memory Tip: devise（动词）与 device（名词）只差一个字母，读音也不同：/dɪˈvaɪz/ 与 /dɪˈvaɪs/。先想"设计出来的东西就是 device"。

常见错误（Common Mistakes）

  • 与 devise 混用，是最常见的拼写错误。
  • 可数：a device / devices。
  • 不指大型机器：大型机组用 machine 或 plant。

Appliance

/əˈplaɪəns/ · noun · 名词

核心释义（Definitions）

  • 家用电器（尤指厨房、清洁类）
  • 器具，装置（正式）

核心搭配（Collocations）

搭配中文释义
household appliances家用电器
a kitchen appliance厨房电器
energy-efficient appliances节能家电
domestic appliances家用器具

例句（Examples）

Writing Task 1 The chart shows the share of electricity used by household appliances.

该图表显示了家用电器用电所占的比重。

Writing Task 2 Replacing old appliances with efficient ones cuts bills faster than changing habits.

把旧家电换成节能款，比改变习惯更能快速降低账单。

Speaking The only appliance I'd never give up is the washing machine.

我唯一不会放弃的家电是洗衣机。

同义替换（Synonyms）

词汇中文释义使用区别
device装置范围更广，不限于家电
gadget小玩意儿口语，指新奇小件
machine机器侧重有动力运转的设备

词根与记忆（Word Formation）

  • Root: apply（应用）+ -ance（名词后缀）
  • Family: appliance 器具 / apply 应用 / application 应用 / applicable 适用的
  • Memory Tip: appliance 是"被应用的东西"——把电用到生活里的器具。所以 household appliances 就是"家用电器"这个固定搭配。

常见错误（Common Mistakes）

  • 家电统称 household appliances，用复数。
  • 拼写 app-li-ance，双 p 单 l。
  • 不用于工业大型设备，那用 machinery。

Facility

/fəˈsɪləti/ · noun · 名词

核心释义（Definitions）

  • 设施，设备（常用复数 facilities）
  • 能力，便利条件；（机构的）附属部门

核心搭配（Collocations）

搭配中文释义
sports facilities体育设施
medical facilities医疗设施
a research facility研究机构
with facilities for具备……的设施

例句（Examples）

Writing Task 1 The map shows the new transport facilities built near the harbour.

该地图显示了港口附近新建的交通设施。

Writing Task 2 Rural clinics lack the facilities to diagnose common conditions, let alone rare ones.

乡村诊所连常见病都缺乏诊断设备，更别说罕见病了。

Speaking The gym has decent facilities but the pool is always crowded.

健身房设施不错，就是泳池总很挤。

同义替换（Synonyms）

词汇中文释义使用区别
equipment设备指可移动的器材，不可数
infrastructure基础设施指道路、管网等大系统
amenities生活便利设施多指生活服务配套

词根与记忆（Word Formation）

  • Root: 拉丁 facilitas ← facilis（容易的）← facere（做）
  • Family: facility 设施 / facilitate 促进 / facile 肤浅的；容易的 / fact 事实
  • Memory Tip: fac = 做，facility 本义是"做起来容易"，引申为"让事情容易的条件"——也就是设施。同族的 facilitate（使便利）在本章后面还会遇到。

常见错误（Common Mistakes）

  • 表"设施"多用复数：sports facilities。
  • 表"能力"时不可数：have a facility for languages（有语言天赋）。
  • 拼写 fac-ility，别写成 facillity。

Equipment

/ɪˈkwɪpmənt/ · noun · 名词

核心释义（Definitions）

  • 设备，器材（总称，不可数）
  • 装备，配备

核心搭配（Collocations）

搭配中文释义
a piece of equipment一件设备
laboratory equipment实验室设备
heavy equipment重型设备
medical equipment医疗设备

例句（Examples）

Writing Task 1 The diagram shows the equipment used to test water quality at each site.

该示意图显示了各站点检测水质所用的设备。

Writing Task 2 Schools in poorer regions often lack basic laboratory equipment.

较贫困地区的学校常常缺少基本的实验设备。

Speaking The climbing equipment was provided, so we only brought boots.

攀登装备是提供的，我们只带了鞋。

同义替换（Synonyms）

词汇中文释义使用区别
gear装备口语，多指运动、户外
apparatus仪器装置正式，指成套实验装置
facilities设施指场地与配套，不是器材

词根与记忆（Word Formation）

  • Root: 古法语 esquiper（为船只配备）← 古诺斯语 skipa（装备船）← skip（船）
  • Family: equipment 设备 / equip 装备 / equipped 配备有……的 / equipage 装备（旧）
  • Memory Tip: 词源与"船"有关：出航前要给船配齐东西，所以 equip 是"配齐装备"。名词 equipment 永远不可数。

常见错误（Common Mistakes）

  • 不可数：equipments ✘；计件用 a piece of equipment。
  • 动词是 equip：equip the lab with new tools。
  • 拼写 equi-pment，注意中间是 p。

Instrument

/ˈɪnstrəmənt/ · noun · 名词

核心释义（Definitions）

  • 仪器，器械（精密测量、医疗、音乐）
  • 工具，手段（比喻）；乐器

核心搭配（Collocations）

搭配中文释义
a measuring instrument测量仪器
musical instruments乐器
an instrument of policy政策工具
surgical instruments手术器械

例句（Examples）

Writing Task 1 The diagram shows the instruments attached to the reactor to record pressure.

该示意图显示了连接在反应器上记录压力的仪器。

Writing Task 2 Standardised tests are a blunt instrument for judging a school.

标准化考试是评判学校的粗糙工具。

Speaking I play two instruments, neither of them well.

我会两种乐器，都不怎么样。

同义替换（Synonyms）

词汇中文释义使用区别
tool工具泛指手工或抽象手段
device装置强调功能，不强调精密
implement器具多指农具、手工工具

词根与记忆（Word Formation）

  • Root: 拉丁 instrumentum ← instruere（布置、建造）= in- + struere（堆建）
  • Family: instrument 仪器 / instrumental 起作用的；器乐的 / instrument panel 仪表盘 / instruct 指导
  • Memory Tip: struere 是"堆建"，所以 instrument 原本是"被搭建起来的东西"。形容词 instrumental 引申为"起关键作用的"：play an instrumental role。

常见错误（Common Mistakes）

  • 乐器是可数名词：play an instrument。
  • instrumental 有两个意思："器乐的"与"起作用的"，看搭配。
  • 拼写 in-stru-ment，中间是 -stru-，容易漏成 instrment。

Tool

/tuːl/ · noun · 名词

核心释义（Definitions）

  • 工具，器具（手工或机械）
  • 手段，方法（比喻）

核心搭配（Collocations）

搭配中文释义
a set of tools一套工具
a powerful tool for用于……的有力工具
use sth as a tool把某物当作工具
machine tools机床

例句（Examples）

Writing Task 1 The photograph shows the simple tools used to cut the stone blocks.

照片显示了切割石块所用的简单工具。

Writing Task 2 Data is only a tool; judgement is what turns it into policy.

数据只是工具，把它变成政策的是判断力。

Speaking You can't fix that with the tools we've got — we need a proper wrench.

用我们这些工具修不了，得有把合适的扳手。

同义替换（Synonyms）

词汇中文释义使用区别
instrument仪器精密、专业，非手工工具
implement器具农具、手工器具，偏正式
utensil用具多指厨房、餐具

词根与记忆（Word Formation）

  • Root: 古英语 tōl（工具），与"准备"同源
  • Family: tool 工具 / toolkit 工具包 / tool bar 工具栏 / machine tool 机床
  • Memory Tip: tool 的比喻义极常用：a tool for change（变革的工具）。写作里比 a method 更有画面，但别过度使用。

常见错误（Common Mistakes）

  • 可数：a tool / tools；统称"工具"也说 tools。
  • "用……做工具"是 use sth as a tool，不加 like。
  • 不指精密仪器，那用 instrument。

Gauge

/ɡeɪdʒ/ · noun · 名词 / verb · 动词

核心释义（Definitions）

  • 名词：量规，仪表（压力表、雨量计）
  • 动词：测量；判断，估计（形势、反应）

核心搭配（Collocations）

搭配中文释义
a pressure gauge压力表
a rain gauge雨量计
gauge the reaction判断反应
gauge how far估计有多远

例句（Examples）

Writing Task 1 The diagram shows a gauge fitted to the tank to show the water level.

该示意图显示了装在罐上显示水位的水位计。

Writing Task 2 Surveys are a rough way to gauge public opinion on technical issues.

调查是判断公众对技术议题看法的一种粗略方式。

Speaking It's hard to gauge how he'll react until you tell him.

在告诉他之前，很难判断他会怎么反应。

同义替换（Synonyms）

词汇中文释义使用区别
measure测量通用词，动名词同形
meter计量表指连续读数的表，如电表
assess评估只用于抽象判断

词根与记忆（Word Formation）

  • Root: 古北法语 gauger（测量水深），词源可能与"横杆"有关
  • Family: gauge 量规；判断 / gauging 测量 / gauge pressure 表压
  • Memory Tip: 名词是"表"，动词是"量"——同形而两类用法。英式拼写 gauge，美式也用 gauge；注意不是 guage。

常见错误（Common Mistakes）

  • 拼写 g-a-u-g-e，最常见的错拼是 guage。
  • 动词义"判断"很实用，可替代 judge，但更强调"估量"。
  • 与 meter 区分：gauge 多指瞬时读数，meter 多指累计计量。

Measure

/ˈmeʒə(r)/ · verb · 动词 / noun · 名词

核心释义（Definitions）

  • 动词：测量，衡量
  • 名词：措施，办法；（测量的）尺度，程度

核心搭配（Collocations）

搭配中文释义
measure the impact衡量影响
take measures to采取措施
a measure of一定程度的
safety measures安全措施

例句（Examples）

Writing Task 1 The chart measures output per worker rather than total output.

该图表衡量的是人均产出，而非总产出。

Writing Task 2 Governments should take measures to limit single-use plastics.

政府应当采取措施限制一次性塑料。

Speaking It's hard to measure progress when nobody agrees on the goal.

目标都没共识时，很难衡量进展。

同义替换（Synonyms）

词汇中文释义使用区别
assess评估侧重判断价值与水平
gauge估量偏"凭感觉估"
step步骤；措施与 measure 近义，口语更常用

词根与记忆（Word Formation）

  • Root: 拉丁 mensura ← metiri（测量）
  • Family: measure 测量 / measurement 测量结果 / measurable 可衡量的 / dimension 尺寸
  • Memory Tip: take measures（采取措施）与 measure（测量）同形不同义，靠搭配区分：measure 后面接宾语是"量"，take measures 是"采取行动"。

常见错误（Common Mistakes）

  • "采取措施"用 take measures，不用 make measures。
  • 表"一定程度的"用 a measure of，后接不可数名词。
  • measurement 可数：take accurate measurements。

Calculate

/ˈkælkjuleɪt/ · verb · 动词

核心释义（Definitions）

  • 计算，核算（数字）
  • 推测，估计；打算（be calculated to do）

  • 聚集，集合（人或物）
  • 收集（信息、证据）；采集（作物）；推断

核心搭配（Collocations）

搭配中文释义
gather information收集信息
gather around围拢过来
gather evidence收集证据
gather that推测，了解到

例句（Examples）

Writing Task 1 The diagram shows how data is gathered from sensors across the site.

该示意图显示了如何从场地各处传感器收集数据。

Writing Task 2 Satellites gather more climate data in a day than researchers once collected in a year.

卫星一天收集的气候数据，比研究者过去一年收集的还多。

Speaking A crowd gathered to watch them raise the bridge section.

一群人聚过来看他们吊起桥段。

同义替换（Synonyms）

词汇中文释义使用区别
collect收集更强调"逐个取回"
assemble集合更正式，多指有组织地聚
accumulate积累强调数量逐渐增加

词根与记忆（Word Formation）

  • Root: 古英语 gaderian（聚拢），与 together 同源
  • Family: gather 聚集 / gathering 聚会 / together 一起 / altogether 完全
  • Memory Tip: gather 与 together 同源，都是"合成一堆"。I gather that...（我推测）是口语里很地道的用法。

常见错误（Common Mistakes）

  • 拼写 g-a-t-h-e-r，别写成 gether。
  • 及物义"收集"直接带宾语：gather data。
  • gathering 作名词指"聚会"，不用来形容"收集"这个动作。

Attach

/əˈtætʃ/ · verb · 动词

核心释义（Definitions）

  • 系上，附上，连接（物理）
  • 附加（文件、条件）；使依附；使重视（attach importance to）

核心搭配（Collocations）

搭配中文释义
attach sth to sth把某物固定到某物上
attach a file附加文件
be attached to依恋；附属于
attach importance to重视

例句（Examples）

Writing Task 1 The diagram shows a sensor attached to the underside of the bridge.

该示意图显示了固定在桥底的传感器。

Writing Task 2 People become attached to technologies long before they understand them.

人们往往在理解某项技术之前就已经离不开它了。

Speaking I've attached the photos to the email — tell me if they don't open.

照片我附在邮件里了，打不开告诉我。

同义替换（Synonyms）

词汇中文释义使用区别
fasten系紧强调固定牢靠
affix贴上正式，多指印章、标签
connect连接可指抽象关系，不必然接触

词根与记忆（Word Formation）

  • Root: 古法语 atachier（固定），可能与"钉子"有关
  • Family: attach 附上 / attachment 附件；依恋 / detached 独立的；超然的 / detach 拆下
  • Memory Tip: 一对反义很好用：attach（附上）↔ detach（拆下）；attached（依恋的）↔ detached（超然的，如 a detached observer）。

常见错误（Common Mistakes）

  • 介词用 to：attach the label to the box。
  • be attached to 是"依恋"，不是"被附上"这么简单，注意语境。
  • 拼写 at-tach，双 t。

Belong

/bɪˈlɒŋ/ · verb · 动词

核心释义（Definitions）

  • 属于（belong to）
  • 应在（某处），适合待在

核心搭配（Collocations）

搭配中文释义
belong to属于
belong in应归入；适合待在
a sense of belonging归属感
personal belongings个人物品

例句（Examples）

Writing Task 1 The artefacts belong to a period when metalworking was still new.

这些器物属于金属加工刚刚出现的时期。

Writing Task 2 A sense of belonging matters more to wellbeing than income does.

归属感对幸福感的重要性超过收入。

Speaking These keys belong to the flat upstairs, not to us.

这些钥匙是楼上那户的，不是我们的。

同义替换（Synonyms）

词汇中文释义使用区别
pertain to属于；关于正式，多指规则、范畴
own拥有主动关系，belong 是被动归属
fit in融入口语，指人际关系

词根与记忆（Word Formation）

  • Root: 中古英语 longen（适合、属于）前加 be-
  • Family: belong 属于 / belonging 归属感 / belongings 随身物品 / longing 渴望（同源 longen）
  • Memory Tip: belong to 不能用于被动，也不能用进行时：It is belonged to me ✘。belongings 永远用复数，指"随身物品"。

常见错误（Common Mistakes）

  • 无被动、无进行时：The book belongs to her。
  • 个人物品说 personal belongings，用复数。
  • belong to（属于）与 belong in（该放在）不同：This belongs in the drawer。
