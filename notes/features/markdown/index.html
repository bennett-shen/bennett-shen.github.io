Markdown 增强语法

约 268 字小于 1 分钟

2026-01-07

主题在标准 Markdown 之上扩展了一批容器语法，写文档时非常省事。

提示容器

::: tip 提示
提示容器适合放补充说明。
:::

::: warning 注意
警告容器用于需要用户留意的边界情况。
:::

::: danger 危险
危险容器用于不可逆操作。
:::

渲染效果：
