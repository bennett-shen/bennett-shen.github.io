1. 以下说法中不正确的是（ ）。

  • A．为提高项目成功的概率尽早开始识别干系人并引导干系人参与
  • B．当项目管理计划制订后，就可以开始首次识别干系人工作了
  • C．识别干系人和引导干系人参与的过程需要迭代开展
  • D．当组织内部或更大领域的干系人群体发生重大变化时，需要重新识别干系人
展开答案与考点收起答案与考点

答案：B｜考点：识别干系人在编制和批准项目章程之前或同时首次开展，此时项目管理计划尚不存在，并非计划制订后才开始（P360）　自编

答案：B｜考点：项目用户群体识别不全，老年用户属于项目干系人而未纳入，说明识别干系人工作不足（P359）　自编

4. A 公司承接了某银行网上银行系统的建设项目，包括应用软件开发、软硬件集成适配、系统运维等多项工作内容。针对该项目，不正确的是（ ）。

  • B．干系人管理工作应由该项目成员分工负责
  • C．干系人管理有助于为项目赢得更多的资源
