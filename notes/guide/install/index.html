安装与启动

约 300 字大约 1 分钟

2026-01-06

环境要求

  • Node.js ^20.19.0 或 >= 22.0.0
  • 包管理器：pnpm 8+ / npm 8+ / yarn 2+

推荐使用 pnpm

本仓库已附带 pnpm-lock.yaml，使用 pnpm 可以保证依赖版本一致。

安装依赖

pnpm install

如果之前用 npm 安装过，先删除 node_modules 与锁文件，避免同一项目混用两种包管理器。

本地开发

pnpm docs:dev

默认在 http://localhost:8080 启动开发服务，Markdown 修改会热更新。

构建与预览

# 构建静态文件到 docs/.vuepress/dist
pnpm docs:build

# 构建后本地预览产物
pnpm docs:preview

发布到 GitHub Pages

源码与站点分仓存放：源码在 bennett-shen/vuepress_plume，构建产物推到 bennett-shen/bennett-shen.github.io 的 master 分支。

# 只推源码
git push

# 推源码 + 构建 + 发布站点
pnpm release

发布只做一半（比如调试产物）时用 pnpm deploy；只推源码不发站点用 SKIP_DEPLOY=1 git push。

常见问题

Node 版本过低时会直接报错

VuePress 2 与 Plume 主题都要求 Node 20.19+，node -v 低于该版本时请先升级。

构建内存不足时，可提高 Node 内存上限：

NODE_OPTIONS=--max_old_space_size=8192 pnpm docs:build
