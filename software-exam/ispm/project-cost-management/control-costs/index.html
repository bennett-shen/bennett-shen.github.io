6 控制成本

约 2570 字大约 9 分钟

2026-11-21

控制成本是监督项目状态，以更新项目成本和管理成本基准变更的过程。本过程的主要作用是在整个项目期间保持对成本基准的维护，需要在整个项目期间开展。

要更新预算，就需要了解截至目前的实际成本；只有经过实施整体变更控制过程的批准，才可以增加预算。只监督资金支出而不考虑支出所完成工作的价值，最多只能算是跟踪资金流；成本控制应重点分析资金支出与完成的相应工作之间的关系，有效成本控制的关键在于管理经批准的成本基准。

控制成本的目标包括：

  • 对造成成本基准变更的因素施加影响；
  • 确保所有变更请求都得到及时处理；
  • 当变更实际发生时，管理这些变更；
  • 确保成本支出不超过批准的资金限额，既不超出按时段、WBS 组件和活动分配的限额，也不超出项目总限额；
  • 监督成本绩效，找出并分析与成本基准间的偏差；
  • 对照资金支出，监督工作绩效；
  • 防止在成本或资源使用报告中出现未经批准的变更；
  • 向干系人报告所有经批准的变更及其相关成本；
  • 设法把预期的成本超支控制在可接受的范围内。

6.1 输入、工具与技术、输出

类别内容
输入项目管理计划（成本管理计划、成本基准、绩效测量基准）；项目资金需求；项目文件（经验教训登记册）；工作绩效数据；组织过程资产
工具与技术专家判断；数据分析（挣值分析、偏差分析、趋势分析、储备分析）；完工尚需绩效指数；项目管理信息系统
输出工作绩效信息；成本预测；变更请求；项目管理计划（更新）；项目文件（更新）

工作绩效数据包含项目状态的数据，例如哪些成本已批准、发生、支付和开具发票。工作绩效信息则是在工作包层级和控制账户层级上评估已执行工作与工作成本的偏差；使用挣值分析的项目，CV、CPI、EAC、VAC 和 TCPI 将记录在工作绩效报告中。

6.2 挣值分析的三个关键指标

挣值分析（EVA）将实际进度和成本绩效与绩效测量基准进行比较，把范围基准、成本基准和进度基准整合起来形成绩效测量基准，并针对每个工作包和控制账户计算、监测三个关键指标。

指标定义要点
计划价值 PV为计划工作分配的经批准的预算，是为完成某活动或 WBS 组成部分而准备的经批准预算不包括管理储备；应把预算分配至项目生命周期各阶段；某时点的 PV 代表应该已经完成的工作；PV 的总和称为绩效测量基准（PMB），项目的总计划价值称为完工预算（BAC）
挣值 EV对已完成工作的测量值，用该工作的批准预算表示计算应与 PMB 相对应，EV 值不得大于相应组件的 PV 总预算；常用于计算项目完成百分比；既要监测增量以判断当前状态，又要监测累计值以判断长期绩效趋势
实际成本 AC在给定时段内执行某活动而实际发生的成本，是为完成与 EV 相对应工作而发生的总成本计算方法必须与 PV、EV 保持一致（如都只算直接工时、直接成本，或都含间接成本）；AC 没有上限，为实现 EV 所花费的任何成本都要计入

6.3 偏差分析与绩效指数

指标公式判定
成本偏差 CVCV = EV − AC正值：低于计划成本（节约）；零：按计划成本；负值：超出计划成本
进度偏差 SVSV = EV − PV正值：比计划提前；零：按计划进行；负值：比计划滞后
完工偏差 VACVAC = BAC − EAC正值：低于计划成本；零：按计划成本；负值：超出计划成本
成本绩效指数 CPICPI = EV / AC大于 1：成本结余；等于 1：按预算；小于 1：成本超支
进度绩效指数 SPISPI = EV / PV大于 1：比计划提前；等于 1：按计划；小于 1：比计划滞后
完工尚需估算 ETCETC = EAC − AC，或重新自下而上估算完成所有剩余项目工作的预计成本

补充判断要点：

  • 偏差分析用以解释 CV、SV 和 VAC 的原因、影响和纠正措施，成本和进度偏差是最需要分析的两种偏差；随着项目逐步完成，偏差的可接受范围（常用百分比表示）将逐步缩小。
  • 项目完工时全部计划价值都将实现（成为挣值），进度偏差最终等于零；CV 为负值一般不可挽回。项目结束时的成本偏差，就是 BAC 与实际成本之间的差值。
  • SPI 测量的是项目的总工作量，还需对关键路径上的绩效单独分析，才能确认项目是否提前或推迟完工；SPI 常与 CPI 一起使用，以预测项目的最终完工估算。
  • 趋势分析通过图表与预测审查绩效随时间的变化，判断绩效正在改善还是恶化；EAC 预测应与手工的自下而上估算相互印证。

6.4 完工估算 EAC 的四种算法

EAC 是完成所有工作所需的预期总成本，等于截至目前的实际成本加上完工尚需估算。计算时通常使用累计 CPI 和累计 SPI。

情形假设公式
自下而上重估以已完成工作的实际成本为基础，根据已积累经验为剩余工作编制新估算EAC = AC + 自下而上的 ETC
按预算单价完成剩余工作承认以实际成本表示的累计绩效，预计未来全部 ETC 工作按预算单价完成EAC = AC + (BAC − EV)
按当前 CPI 继续项目按截至目前的情况继续，ETC 工作按累计 CPI 实施EAC = BAC / CPI
CPI 与 SPI 同时影响由 CPI 与 SPI 综合决定的效率指标完成 ETC 工作，可按判断赋权重（如 80/20、50/50）EAC = AC + (BAC − EV) / (CPI × SPI)

如果 BAC 已明显不再可行，项目经理应考虑对 EAC 进行预测；若目前的实际绩效不好，只有在进行项目风险分析并取得有力证据后，才能假设“未来绩效将会改进”。当进度对 ETC 有重要影响时，CPI 与 SPI 综合法最有效。

6.5 完工尚需绩效指数 TCPI

TCPI 是为了实现特定的管理目标，剩余资源的使用必须达到的成本绩效指标，即完成剩余工作所需的成本与剩余预算之比，也就是“为了完成计划必须保持的效率”。

基准公式判定
基于 BAC（BAC 仍可行）TCPI = (BAC − EV) / (BAC − AC)大于 1：难以完成；等于 1：正好完成；小于 1：轻易完成
基于 EAC（BAC 不再可行，经批准后用 EAC 取代 BAC）TCPI = (BAC − EV) / (EAC − AC)同上，衡量完成当前完工估算必须保持的效率

若累计 CPI 低于基准，则全部剩余工作都应立即按 TCPI（BAC）执行，才能确保实际总成本不超过批准的 BAC；这种绩效水平是否可行，需综合考虑风险、项目剩余时间和技术绩效后判断，若不可行，则需把未来所需绩效水平调整为 TCPI（EAC）。

6.6 储备分析与过程输出

控制成本中的储备分析用于监督应急储备和管理储备的使用情况，从而判断是否还需要这些储备，或者是否需要增加额外的储备。

  • 随着项目工作的进展，储备可能已按计划用于支付风险或其他应急情况的成本；
  • 如果抓住机会节约了成本，节约下来的资金可能会增加到应急储备中，或作为盈利/利润从项目中剥离；
  • 如果已识别的风险没有发生，可能要从项目预算中扣除未使用的应急储备，为其他项目或运营腾出资源；进一步的风险分析也可能要求追加储备。

本过程的输出包括：

  • 工作绩效信息：对照成本基准，在工作包层级和控制账户层级评估已执行工作与工作成本的偏差；
  • 成本预测：无论计算得出的 EAC 还是自下而上估算的 EAC，都需记录下来并传达给干系人；
  • 变更请求：可能针对成本基准、进度基准或项目管理计划的其他组成部分提出，应通过实施整体变更控制过程审查处理；
  • 项目管理计划（更新）：成本管理计划（控制临界值、要求的准确度）、成本基准、绩效测量基准；偏差过于严重时需修订基准，以便为绩效测量提供现实可行的依据；
  • 项目文件（更新）：假设日志、估算依据、成本估算、经验教训登记册、风险登记册。
