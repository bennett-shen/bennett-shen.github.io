Linguistics

/lɪŋˈɡwɪstɪks/ · noun · 名词

核心释义（Definitions）

  • 语言学（研究语言结构、声音与意义的学科）

核心搭配（Collocations）

搭配中文释义
applied linguistics应用语言学
comparative linguistics比较语言学
a degree in linguistics语言学学位
the linguistics department语言学系
historical linguistics历史语言学

例句（Examples）

Writing Task 1 The table shows the number of students enrolled in linguistics and three other humanities subjects in 2020.

该表格显示了 2020 年语言学与另外三个人文学科的选课人数。

Writing Task 2 Linguistics supplies the tools for describing how languages change, but it rarely predicts which changes a society will accept.

语言学提供了描述语言如何变化的工具，但很少能预测一个社会会接受哪些变化。

Speaking My cousin studied linguistics and now designs voice assistants — apparently that's a fairly common route.

我表姐学语言学，现在做语音助手，据说这是相当常见的一条路。

同义替换（Synonyms）

词汇中文释义使用区别
philology语文学偏历史文献考据，重文本不重口语
language studies语言研究泛指，不是严格的学科名
grammar语法只是语言学的一个分支
phonetics语音学同样是分支，范围窄得多

词根与记忆（Word Formation）

  • Root: 拉丁 lingua（舌头）+ -istics（学科后缀）
  • Family: linguist 语言学家 / linguistic 语言的 / bilingual 双语的 / multilingual 多语的
  • Memory Tip: -ics 是学科后缀（physics、economics、ethics），所以哪怕指一门学科也带 -s，动词永远用单数。

常见错误（Common Mistakes）

  • 形式是复数、意义是单数：Linguistics is fascinating；are ✘。
  • 形容词用 linguistic：linguistic analysis ✔ / linguistics analysis ✘。
  • 别与 linguist（语言学家）混：He is a linguist，不是 a linguistics。

Semantic

/sɪˈmæntɪk/ · adj · 形容词

核心释义（Definitions）

  • 语义的，词义的
  • （逻辑中）关于真值的

核心搭配（Collocations）

搭配中文释义
a semantic difference语义上的差别
semantic change语义演变
a semantic field语义场
semantic overlap语义重叠
a purely semantic objection纯属措辞上的反对

例句（Examples）

Writing Task 1 The table groups the responses by semantic category rather than by frequency of use.

该表格按语义类别而非使用频率对回答进行了归类。

Writing Task 2 The semantic gap between "refugee" and "migrant" shapes how the public responds to each word.

"难民"与"移民"之间的语义落差，影响着公众对这两个词的反应。

Speaking There's a semantic difference between "cheap" and "affordable", and advertisers know it.

"便宜"和"实惠"在语义上是有差别的，广告商很清楚这一点。

同义替换（Synonyms）

词汇中文释义使用区别
lexical词汇的指词项层面，常与 semantic 并列使用
conceptual概念的强调思维层面，不是语言符号层面
definitional定义上的只涉及定义表述，范围更窄
linguistic语言的上位词，涵盖语音、语法等

词根与记忆（Word Formation）

  • Root: 希腊 sēma（记号、符号）+ -ic
  • Family: semantics 语义学 / semiotics 符号学 / semaphore 旗语 / semanticist 语义学家
  • Memory Tip: sēma 是"记号"——记号指向的意义就是语义。同根的 semaphore 是"用旗子做记号"，读起来像"信号"，联想很顺。

常见错误（Common Mistakes）

  • 一般只作定语，不用比较级：more semantic 罕见。
  • 名词是 semantics，作单数：Semantics deals with meaning。
  • 别与 sematic（"警戒色的"，生僻）混淆，拼写只差一个 n。

Syntax

/ˈsɪntæks/ · noun · 名词

核心释义（Definitions）

  • 句法（词与词组合成句的规则）
  • （计算机）语法，语句结构

核心搭配（Collocations）

搭配中文释义
English syntax英语句法
a syntax error语法错误（编程）
complex syntax复杂的句法结构
the syntax of a sentence句子的句法结构
syntax and morphology句法与词法

例句（Examples）

Writing Task 1 The bar chart compares sentence length and syntactic complexity across four textbook series.

该柱状图比较了四套教材在句长与句法复杂度上的差异。

Writing Task 2 Children acquire the syntax of their native language without explicit instruction.

儿童无需明确教学就能习得母语的句法。

Speaking My essay was marked down for syntax, not vocabulary — every sentence had the same shape.

我的文章扣分在句法不在词汇，每句话都是同一个模子。

同义替换（Synonyms）

词汇中文释义使用区别
grammar语法上位概念，含词法与句法
sentence structure句子结构描述性说法，非术语
word order语序只是句法的一部分
morphology词法研究词内结构，与句法并列

词根与记忆（Word Formation）

  • Root: 希腊 syn-（一起）+ tassein（排列）→ "排在一起"
  • Family: syntactic 句法的 / tactics 战术（同源，原义"排列"）/ taxis? / syntagm 组合段
  • Memory Tip: syn + taxis = "排列在一起"。词排在一起要讲顺序，这就是句法；军队排列叫 tactics，同一个"排列"。

常见错误（Common Mistakes）

  • 不可数：syntaxes 极少见；说 patterns of syntax。
  • 形容词是 syntactic：syntactic complexity ✔ / syntax complexity ✘。
  • 编程里的 syntax error 是固定说法，别改成 grammar error。

Grammar

/ˈɡræmə(r)/ · noun · 名词

核心释义（Definitions）

  • 语法（语言的规则系统）
  • 语法书
  • （英式）grammar school 指公立中学（旧制择优）

核心搭配（Collocations）

搭配中文释义
English grammar英语语法
grammar rules语法规则
a grammar mistake语法错误
grammar and vocabulary语法与词汇
grammar school（英）公立中学

例句（Examples）

Writing Task 1 The table shows the proportion of marks awarded for grammar, vocabulary and task response.

该表格显示了语法、词汇与任务完成度各自的分数占比。

Writing Task 2 Teaching grammar in isolation rarely improves writing; students need to use structures in context.

孤立地教语法很少能提高写作，学生需要在语境中使用这些结构。

Speaking I only really understood English grammar once I started learning German.

我是开始学德语之后才真正搞懂英语语法的。

同义替换（Synonyms）

词汇中文释义使用区别
syntax句法语法的一部分，只讲句子结构
usage用法讲实际使用习惯，不是规则体系
rules规则泛指，非术语
mechanics书写规范指拼写、标点等书面细节

词根与记忆（Word Formation）

  • Root: 希腊 gramma（写下的东西、字母）
  • Family: grammatical 语法的 / grammarian 语法学家 / diagram 图解 / telegram 电报 / program 程序
  • Memory Tip: gramma 是"写下的字母"，研究写下来的规矩就是语法。同一词根到处是"写"：telegram 远距离写，diagram 画着写。

常见错误（Common Mistakes）

  • 指规则体系时不可数；"一本语法书"可数：a grammar of English。
  • grammar school 在英国指公立中学，不译作"语法学校"。
  • 形容词是 grammatical：grammatical error ✔ / grammar error 口语可接受但不正式。

Phonetics

/fəˈnetɪks/ · noun · 名词

核心释义（Definitions）

  • 语音学（研究语音的产生、传递与感知）

核心搭配（Collocations）

搭配中文释义
the phonetics of English英语语音
practical phonetics实用语音学
phonetics and phonology语音学与音系学
phonetic transcription音标转写
the phonetic alphabet音标字母表

例句（Examples）

Writing Task 1 The diagram labels each speech organ involved in the phonetics of the vowel sounds.

该图标注了元音发音所涉及的各个发音器官。

Writing Task 2 A grounding in phonetics helps learners hear distinctions that their first language ignores.

语音学基础能帮助学习者听出母语所忽略的区别。

Speaking Phonetics was the only class where we spent an hour making noises at each other.

语音学是唯一一门我们花一小时互相发怪声的课。

同义替换（Synonyms）

词汇中文释义使用区别
phonology音系学研究语音的系统规则，不是物理发音
pronunciation发音指实际读法，是技能不是学科
articulation发音动作指器官如何动作，范围窄
phonics自然拼读儿童识字教学法，不是学科

词根与记忆（Word Formation）

  • Root: 希腊 phōnē（声音）+ -etics
  • Family: phone 音子 / phoneme 音位 / telephone 电话 / symphony 交响乐 / phonetic 语音的
  • Memory Tip: phon 就是"声音"：telephone 把声音传远，symphony 让声音一起响，phonetics 则是把声音本身当对象研究。

常见错误（Common Mistakes）

  • 学科名作单数：Phonetics is compulsory；are ✘。
  • 别与 phonics 混：phonics 是教孩子拼读的方法。
  • 形容词 phonetic，不是 phonetical。

Pronounce

/prəˈnaʊns/ · verb · 动词

核心释义（Definitions）

  • 发音，读出
  • 宣布，宣告；（法庭）宣判

核心搭配（Collocations）

搭配中文释义
pronounce a word correctly正确读出一个词
how do you pronounce ...?……怎么读？
pronounce sentence宣判
pronounce something a success宣布某事成功
be pronounced dead被宣告死亡

例句（Examples）

Writing Task 1 The table lists ten words and shows how the share of students who could pronounce them correctly changed over five years.

该表格列出十个单词，并显示能正确读出这些词的学生比例在五年间的变化。

Writing Task 2 Teachers who never pronounce unfamiliar names correctly send a quiet message about whose language matters.

从不把陌生名字念对的教师，其实在无声地暗示谁的语言更重要。

Speaking I still can't pronounce "rural" without sounding like I'm choking.

我还是读不好 rural，一读就像被噎住了。

同义替换（Synonyms）

词汇中文释义使用区别
articulate清晰发出强调咬字清楚，不指读音对错
enunciate咬字清晰正式，多用于演讲训练
say说泛用词，不含"发音是否正确"
voice发（音）指发出某个音，如 voice a consonant

词根与记忆（Word Formation）

  • Root: 拉丁 pro-（出）+ nuntiare（报信）→ "报出来"
  • Family: pronunciation 发音 / announcement 公告 / denounce 谴责 / nuncio 教廷使节
  • Memory Tip: 记住动词 pronounce 有 ou，名词 pronunciation 没有第二个 o —— 这是英语拼写最经典的坑之一。

常见错误（Common Mistakes）

  • 名词拼写是 pronunciation：pronounciation ✘。
  • 读音：动词 /prəˈnaʊns/，名词 /prəˌnʌnsiˈeɪʃn/，元音完全不同。
  • "这个词怎么读"说 How do you pronounce it?，不说 How do you pronounce?。

Intonation

/ˌɪntəˈneɪʃn/ · noun · 名词

核心释义（Definitions）

  • 语调（句子层面音高的升降）
  • 吟诵，拖长的调子

核心搭配（Collocations）

搭配中文释义
rising intonation升调
falling intonation降调
intonation patterns语调模式
a flat intonation平直的语调
the intonation of a question疑问句的语调

例句（Examples）

Writing Task 1 The graph tracks pitch over time, showing the rising intonation typical of yes/no questions.

该图追踪音高随时间的变化，显示一般疑问句典型的升调。

Writing Task 2 Intonation often carries meaning the words leave open — sarcasm, doubt, politeness.

语调常常承载词语本身没有说定的意思——讽刺、怀疑、客气。

Speaking My flat intonation made my English sound unfriendly, even when I was being polite.

我平直的语调让英语听起来很不友好，哪怕我本意很客气。

同义替换（Synonyms）

词汇中文释义使用区别
tone声调；语气汉语的四声是 tone，词汇层面
pitch音高物理属性，语调由它构成
stress重音指音强与突出，不是升降
cadence抑扬顿挫偏文学，多形容韵律感

词根与记忆（Word Formation）

  • Root: 拉丁 in- + tonus（音调）← 希腊 teinein（拉紧）
  • Family: tone 音调 / tonal 声调的 / monotone 单调 / intone 吟诵
  • Memory Tip: 汉语的"声调"是 tone（一个字一个调），英语句子的升降是 intonation（一句话一条曲线）。层级不同，别混。

常见错误（Common Mistakes）

  • 不可数：intonations 一般不用；说 patterns of intonation。
  • 与 tone 区分：tone 是词内声调或语气，intonation 是句子音高走势。
  • 拼写 intonation，不写 intonnation。

Inflection

/ɪnˈflekʃn/ · noun · 名词

核心释义（Definitions）

  • 屈折变化（词形随语法功能改变，如 -s、-ed）
  • 语调的抑扬；（曲线）拐点

核心搭配（Collocations）

搭配中文释义
verb inflection动词屈折变化
inflectional endings屈折词尾
a rising inflection上扬的语调
without inflection没有语调起伏
a point of inflection拐点

例句（Examples）

Writing Task 1 The table compares how many inflections English and Latin verbs take.

该表格比较了英语与拉丁语动词的屈折变化数量。

Writing Task 2 Children master the inflection of regular verbs before irregular ones, which is why "goed" appears so often.

儿童先掌握规则动词的屈折变化，再掌握不规则的，所以常说出 "goed"。

Speaking Her voice had a slight upward inflection at the end of every sentence, as if everything were a question.

她每句话末尾都微微上扬，好像什么都是问句。

同义替换（Synonyms）

词汇中文释义使用区别
conjugation动词变位只指动词的屈折
declension名词变格只指名词、形容词的屈折
ending词尾描述性说法，不含系统性
intonation语调只对应"抑扬"这一义项

词根与记忆（Word Formation）

  • Root: 拉丁 in- + flectere（弯曲）→ "向内弯"
  • Family: flexible 灵活的 / reflect 反射 / deflect 偏转 / flection 弯曲
  • Memory Tip: flect 是"弯"：词形随语法"弯"一下就是屈折，声音"弯"一下就是语调上扬，曲线"弯"一下就是拐点——三个义项一个动作。

常见错误（Common Mistakes）

  • 与 intonation 分工：语法上讲"屈折变化"，语音上讲"语调抑扬"，同一词两副面孔。
  • 拼写 -tion，不写 -tation。
  • 语言学语境不可数；指具体词尾时可数：three inflections。

Dialect

/ˈdaɪəlekt/ · noun · 名词

核心释义（Definitions）

  • 方言，土语（一个地区的语言变体，含词汇、语法与发音差异）

核心搭配（Collocations）

搭配中文释义
a regional dialect地域方言
speak a dialect说方言
the local dialect当地方言
dialect words方言词
a dialect of Chinese汉语的一种方言

例句（Examples）

Writing Task 1 The map shows where each dialect is spoken and how the boundaries have shifted since 1950.

该地图显示了各方言的使用区域，以及 1950 年以来方言边界的变化。

Writing Task 2 Schools that punish dialect use may raise test scores while quietly erasing local identity.

惩罚使用方言的学校或许能提高考试分数，却在悄悄抹去地方认同。

Speaking My grandmother speaks a dialect I can understand but can't reproduce at all.

我奶奶说的方言我能听懂，但一句也学不来。

同义替换（Synonyms）

词汇中文释义使用区别
accent口音只涉及发音，不涉及词汇语法
vernacular本地话正式用语，强调"当地日常说的"
patois土话常带轻蔑色彩，指小地方的变体
variety变体学术中性词，含方言与社会变体

词根与记忆（Word Formation）

  • Root: 希腊 dia-（之间）+ legein（说）→ "某些人之间说的话"
  • Family: dialectal 方言的 / idiolect 个人语型 / lect 语言变体 / dialectology 方言学
  • Memory Tip: dia 是"之间"，lect 是"说"：一群人之间说的话就是方言。个人自己的一套说法叫 idiolect（idio = 自己的）。

常见错误（Common Mistakes）

  • 最常与 accent 混：dialect 含词汇与语法差异，accent 只指发音。
  • 可数：a dialect、many dialects。
  • "说方言"用 speak a dialect，不用 say a dialect。

Accent

/ˈæksent/ · noun · 名词（动词 /əkˈsent/）

核心释义（Definitions）

  • 口音（一个人或一群人的发音特征）
  • 重音，重读；（符号）重音符号
  • 动词：强调，重读

核心搭配（Collocations）

搭配中文释义
a strong accent浓重的口音
speak with an accent带口音说话
a foreign accent外国口音
the accent falls on the first syllable重音在第一音节
put the accent on强调；重读

例句（Examples）

Writing Task 1 The chart shows where respondents placed the primary accent in each of the ten words.

该图显示了受访者在十个单词上各自把主重音放在什么位置。

Writing Task 2 Judging someone by their accent says more about the listener than about the speaker.

凭口音判断一个人，暴露的其实是听者而非说者。

Speaking I picked up a slight Australian accent after two years in Melbourne, and now I can't lose it.

在墨尔本待了两年，我染上了一点澳洲口音，现在改不掉了。

同义替换（Synonyms）

词汇中文释义使用区别
pronunciation发音指具体读法，不含"地域特征"
stress重音只对应"重读"义项
intonation语调指句子升降，不是口音
twang鼻音腔口语，带贬义或戏谑

词根与记忆（Word Formation）

  • Root: 拉丁 ad-（向）+ cantus（唱）→ "附加的调子"
  • Family: accentuate 强调 / accentual 重音的 / chant 吟唱 / incantation 咒语
  • Memory Tip: cant 是"唱"：给词"加一段调"就是重音，给人"加一段调"就是口音。名词重音在前，动词在后——record 也是这个套路。

常见错误（Common Mistakes）

  • 名词重音在前 /ˈæksent/，动词在后 /əkˈsent/。
  • "美国口音"是 an American accent，不说 an accent of America。
  • accent 与 dialect 不同：前者只关发音。

Utterance

/ˈʌtərəns/ · noun · 名词

核心释义（Definitions）

  • 话语，（说出口的）一句话
  • 言论，表述（常带正式或批评色彩）

核心搭配（Collocations）

搭配中文释义
a single utterance一句话
public utterances公开言论
a recorded utterance录制的话语
a meaningful utterance有意义的话语
an utterance act言语行为

例句（Examples）

Writing Task 1 The table counts the number of utterances each child produced in a ten-minute recording.

该表格统计了每个孩子在十分钟录音中说出的话语数量。

Writing Task 2 A single careless utterance can undo years of careful diplomacy.

一句不慎的话，就能毁掉多年的外交经营。

Speaking Linguists recorded our utterances and played them back — I had no idea I said "like" that often.

语言学家录下我们说的话再放回来，我都不知道自己 "like" 说得那么频繁。

同义替换（Synonyms）

词汇中文释义使用区别
statement陈述偏正式表态，可书面
remark评论随口说出的话，语气轻
speech言语指口头表达这一能力或行为
comment评论针对某事的看法

词根与记忆（Word Formation）

  • Root: 古英语 ūttera（外部的）→ utter（说出）
  • Family: utter 完全的；说出 / utterly 彻底地 / utterance 话语
  • Memory Tip: utter 有两副面孔：动词"说出"（把话"送出去"），形容词"彻底的"（utter nonsense 一派胡言）。utterance 只继承"说出"这一支。

常见错误（Common Mistakes）

  • 语言学中指"话语单位"；日常语境略带正式或批评意味，别当中性"句子"用。
  • 可数：an utterance、several utterances。
  • 拼写双 t：utterance。

Oral

/ˈɔːrəl/ · adj · 形容词 / noun · 名词

核心释义（Definitions）

  • 形容词：口头的；口腔的
  • 名词：口试（英式，an oral）

核心搭配（Collocations）

搭配中文释义
an oral exam口试
oral tradition口述传统
oral history口述史
oral hygiene口腔卫生
oral communication口头交流

例句（Examples）

Writing Task 1 The chart compares students' scores in the written and oral components of the test.

该图比较了学生在考试笔试与口试部分的得分。

Writing Task 2 Oral traditions preserved genealogies for centuries before anyone wrote them down.

在有人写下族谱之前，口述传统已将其保存了数百年。

Speaking I'd much rather take an oral exam than write a three-hour paper.

我宁愿参加口试，也不想写三个小时的论文。

同义替换（Synonyms）

词汇中文释义使用区别
spoken口头的最直白，专与 written 相对
verbal言语的可指口头也可指文字，范围更宽
vocal发声的强调用嗓音发出
unwritten未成文的只对应"口述传统"类语境

词根与记忆（Word Formation）

  • Root: 拉丁 os / oris（嘴）
  • Family: orally 口头地 / orator 演说家 / orifice 孔口 / peroral 经口的
  • Memory Tip: or 是"嘴"：oral 就是"用嘴的"。orator 是用嘴吃饭的人——靠演讲为生；orifice 是身上的"口"。

常见错误（Common Mistakes）

  • oral 与 verbal 常混：oral 强调"用嘴说"，verbal 强调"用语言"，书面也算 verbal。
  • 医学语境 oral 指"口服的"：oral vaccine 口服疫苗。
  • 口试在英式英语中可说 an oral，美式多说 an oral exam。

Verbal

/ˈvɜːbl/ · adj · 形容词

核心释义（Definitions）

  • 言语的，文字的（与语言有关）
  • 口头的（与书面相对）

核心搭配（Collocations）

搭配中文释义
verbal communication言语交流
a verbal agreement口头协议
verbal abuse言语辱骂
verbal skills语言能力
non-verbal cues非言语信号

例句（Examples）

Writing Task 1 The graph compares verbal and non-verbal scores across three age groups.

该图比较了三个年龄组在言语与非言语测试上的得分。

Writing Task 2 A verbal agreement is still a contract, but it is far harder to prove in court.

口头协议仍是合同，只是法庭上要证明它困难得多。

Speaking Most of what we call conversation is non-verbal — posture, timing, eye contact.

我们所谓的交谈，大部分是非言语的：姿态、时机、眼神。

同义替换（Synonyms）

词汇中文释义使用区别
oral口头的只指"用嘴说"，不含书面
spoken口语的与 written 直接对立
linguistic语言的学术用语，指语言系统
wordy冗长的贬义，指话多

词根与记忆（Word Formation）

  • Root: 拉丁 verbum（词）
  • Family: verb 动词 / verbose 啰嗦的 / verbatim 逐字的 / verbalise 用言语表达
  • Memory Tip: verbum 是"词"：凡是与"词"有关的都是 verbal。所以 verbal skills 是"语言能力"，不等于"口头能力"——写作能力也算。

常见错误（Common Mistakes）

  • verbal 不等于 oral：合同里想强调"口头的"，用 oral agreement 更严谨。
  • non-verbal 带连字符：non-verbal communication。
  • 别与 verbose（啰嗦）混，词根同源但意思差很远。

Syllable

/ˈsɪləbl/ · noun · 名词

核心释义（Definitions）

  • 音节（一个元音核加相邻辅音构成的最小发音单位）

核心搭配（Collocations）

搭配中文释义
a stressed syllable重读音节
a two-syllable word双音节词
count the syllables数音节
the first syllable第一个音节
break a word into syllables把词分成音节

例句（Examples）

Writing Task 1 The table groups the words by number of syllables and shows the stress pattern of each.

该表格按音节数给单词分组，并列出各自的重音模式。

Writing Task 2 Poets count syllables the way musicians count beats, and the effect on meaning is just as real.

诗人数字节如同音乐家数拍子，对意义的影响同样真实。

Speaking I only learned what a syllable was when I tried to write a haiku in English.

我是试着用英语写俳句时，才搞清什么叫音节的。

同义替换（Synonyms）

词汇中文释义使用区别
beat拍诗歌与口语中的通俗说法
mora摩拉日语等的计时单位，不等于音节
stress重音音节的属性，不是音节本身
foot音步诗歌韵律单位，含多个音节

词根与记忆（Word Formation）

  • Root: 希腊 syllabē（合在一起）← syn- + lambanein（拿）
  • Family: syllabic 音节的 / monosyllable 单音节词 / polysyllabic 多音节的 / syllable-timed 音节计时的
  • Memory Tip: 原义是"把几个音抓在一起"——辅音抓住元音，抱成一团就是一个音节。所以一个音节里必有一个响亮的元音核。

常见错误（Common Mistakes）

  • 音节数不等于字母数：queue 是一个音节，strengths 也是一个。
  • "重音在第二音节"说 the stress falls on the second syllable，介词用 on。
  • 拼写 syllable 双 l，不写 sylable。

Phoneme

/ˈfəʊniːm/ · noun · 名词

核心释义（Definitions）

  • 音位，音素（能区别意义的最小语音单位）

核心搭配（Collocations）

搭配中文释义
the /p/ phoneme/p/ 音位
distinguish two phonemes区分两个音位
the phoneme inventory of a language一种语言的音位系统
phonemes and allophones音位与音位变体

例句（Examples）

Writing Task 1 The chart shows the number of phonemes in five languages, ranging from eleven to over forty.

该图显示了五种语言的音位数量，从十一个到四十多个不等。

Writing Task 2 Two sounds may be distinct phonemes in one language and mere variants in another.

两个音在一种语言里可能是不同的音位，在另一种语言里只是变体。

Speaking In English /l/ and /r/ are separate phonemes, which is why "rice" and "lice" aren't funny to my teacher.

英语里 /l/ 和 /r/ 是两个音位，所以我老师说 rice 和 lice 一点都不好笑。

同义替换（Synonyms）

词汇中文释义使用区别
phone音子实际发出的音，不承担区别意义的功能
allophone音位变体同一音位的不同实际读法
sound声音日常泛称，无术语精度
letter字母书写单位，与音位不对应

词根与记忆（Word Formation）

  • Root: 希腊 phōnē（声音）+ -eme（区别性单位，仿 morpheme）
  • Family: phone 音子 / phonetics 语音学 / homophone 同音词 / telephone 电话
  • Memory Tip: -eme 是"能区别意义的最小单位"：morpheme 区别意义，phoneme 区别声音。换一个音位，词就变成另一个词（pin / bin）。

常见错误（Common Mistakes）

  • phoneme 是功能单位，phone 是物理声音；写作中别混。
  • 拼写 -eme，不写 -eam 或 -eem。
  • 音位用斜杠标注：/p/；实际发音用方括号：[pʰ]。

Vowel

/ˈvaʊəl/ · noun · 名词

核心释义（Definitions）

  • 元音，元音音素
  • 元音字母（a、e、i、o、u）

核心搭配（Collocations）

搭配中文释义
a long / short vowel长元音／短元音
vowel sounds元音音素
the Great Vowel Shift元音大推移
a rounded vowel圆唇元音
consonants and vowels辅音与元音

例句（Examples）

Writing Task 1 The diagram shows the position of the tongue for five vowel sounds.

该图展示了五个元音发音时舌位的位置。

Writing Task 2 The Great Vowel Shift explains why English spelling and pronunciation diverge so wildly.

元音大推移解释了英语拼写与读音为何差异如此之大。

Speaking English has far more vowel sounds than vowel letters, which is why "though" and "tough" don't rhyme.

英语的元音音素远多于元音字母，所以 though 和 tough 不押韵。

同义替换（Synonyms）

词汇中文释义使用区别
vowel sound元音音素明确指声音而非字母
diphthong双元音两个元音滑动而成，是一个音节
nucleus音节核音节中最响的部分，通常由元音充当

词根与记忆（Word Formation）

  • Root: 拉丁 vocalis（发声的）← vox（声音）
  • Family: vocal 声音的 / voice 嗓音 / vocable 词 / vocative 呼语
  • Memory Tip: vox 是"声音"：元音是"能唱出来的音"，所以叫 vowel；辅音得靠元音才能响。唱长音时你发的全是元音。

常见错误（Common Mistakes）

  • 分清 vowel letter（字母）与 vowel sound（音素）：字母 5 个，音素近 20 个。
  • 不定冠词看读音不看字母：an hour（h 不发音）、a university（/juː/ 起头）。
  • 拼写 vowel，不写 vowell。

Consonant

/ˈkɒnsənənt/ · noun · 名词 / adj · 形容词

核心释义（Definitions）

  • 名词：辅音，辅音字母
  • 形容词：一致的，符合的（be consonant with）

核心搭配（Collocations）

搭配中文释义
consonant clusters辅音连缀
voiced / unvoiced consonants浊辅音／清辅音
a consonant sound辅音音素
be consonant with与……一致
consonants and vowels辅音与元音

例句（Examples）

Writing Task 1 The table compares the number of consonant clusters in English and Japanese.

该表格比较了英语与日语的辅音连缀数量。

Writing Task 2 The policy is consonant with the government's stated commitment to cut emissions.

该政策与政府公开承诺的减排目标是一致的。

Speaking Consonant clusters like those in "strengths" are what make English so hard to pronounce.

像 strengths 里的辅音连缀，正是英语难读的原因。

同义替换（Synonyms）

词汇中文释义使用区别
consonant sound辅音音素明确指声音，不是字母
cluster连缀指辅音的组合，不是单个辅音
consistent一致的只对应形容词义，语气更常用
compatible相容的强调可共存，不强调"符合规定"

词根与记忆（Word Formation）

  • Root: 拉丁 con-（一起）+ sonare（响）→ "一起发声"
  • Family: sonata 奏鸣曲 / resonance 共鸣 / sonic 声音的 / sonorous 洪亮的
  • Memory Tip: 辅音不能单独成响，必须"和元音一起响"，所以叫 con + sonant。形容词义"一致"是同一个道理：两件事能一起响，就是协调。

常见错误（Common Mistakes）

  • 形容词义 be consonant with，不用 to。
  • 可数：a consonant、double consonants。
  • 拼写 -sonant 中间是 o，不写 -sanant。
